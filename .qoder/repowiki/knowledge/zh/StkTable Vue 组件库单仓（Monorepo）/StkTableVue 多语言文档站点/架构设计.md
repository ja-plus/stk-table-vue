站点以 VitePress 为核心框架，入口配置位于 `.vitepress/config.ts`，通过 `locales` 字段同时挂载 root（中文）、en、ja、ko 四个语言包；每个语言的导航与侧边栏在对应语言的 `main/` 目录下按 `start`、`table/basic`、`table/advanced/custom-cells`、`api`、`other` 等目录组织 Markdown 页面，`demos/` 与 `public/assets/` 存放跨语言共享的示例与静态资源。示例代码通过 `vitepress-demo-plugin` 从外部 `docs-demo` 目录注入 `<demo>` 标签渲染，Markdown 中通过 `vue` 和 `github` 属性引用 Vue SFC 源码并链接到 GitHub。多语言主题配置由 `.vitepress/src/config/{zh,en,ja,ko}.ts` 分别定义，主配置通过展开运算符合并到各 locale。PostCSS 通过 `postcss.config.mjs` 独立管理样式隔离管线，`vitepress-plugin-llms` 插件用于生成 LLM 文本索引。
