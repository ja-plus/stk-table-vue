该仓库是一个 Vue 3 表格组件库工程，未实现运行时配置系统（如 .env、application.properties、feature flags 等），而是通过构建期配置文件管理项目行为。核心配置集中在以下位置：

1. **构建配置**：`vite.config.ts` 定义库打包入口（`src/StkTable/index.ts`）、输出目录（`lib/`）、目标浏览器（chrome84）、CSS 命名规则（`style.css`）、别名（`@` → `src`）以及插件链（vue、banner、dts）。生产环境启用 d.ts 生成。

2. **包元数据**：`package.json` 声明 pnpm 包管理器、脚本命令（dev/build/test/docs:*）、发布文件（lib、src）、依赖及类型入口。

3. **文档站点配置**：`docs-src/.vitepress/config.ts` 使用 VitePress 多语言配置（中/英/日/韩），集成 demo 插件和 LLMs 插件，文档源位于 `docs-demo/`。

4. **环境变量**：仅 `vite.config.ts` 中使用 `process.env.NODE_ENV` 区分生产环境以启用 d.ts 生成，无 `.env` 文件或运行时环境变量注入。

5. **样式与工具链**：`postcss.config.js`、`.eslintrc.cjs`、`.prettierrc.cjs`、`tsconfig.json`、`vitest.workspace.ts` 分别管理 CSS 处理、代码规范、格式化、TypeScript 编译和测试框架。

该工程采用「构建期配置」模式，所有配置在打包时固化到产物中，无运行时配置加载逻辑。
