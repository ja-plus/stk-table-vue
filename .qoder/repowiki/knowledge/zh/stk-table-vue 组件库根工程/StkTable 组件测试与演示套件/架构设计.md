测试目录按职责分为三类：
- 单元测试（`*.test.js` / `*.test.ts`）：使用 Vitest + @vue/test-utils 对 StkTable 的行为进行断言，如 `defaultSort.test.js`、`setSorter.test.js`、`formatNumber.test.ts`、`insertToOrderedArray.test.js`；其中 `StkTable.browser.test.js` 通过 `@vitest-environment happy-dom` 指令在 DOM 环境中挂载组件，验证渲染、溢出、无数据兜底及 areaSelection 暴露方法。
- 演示页面（`.vue` 单文件）：每个 `.vue` 文件独立展示一个功能场景（如 `AutoRowHeight.vue`、`VirtualTree.vue`、`StkTableMultiHeader.vue`、`DocTable.vue` 等），直接 import `../src/StkTable/index` 中的 StkTable 并传入 props 演示用法。
- 工具模块（`utils/`）：`h.js` 实现轻量级 createElement 辅助函数，`DragResize.js` 封装拖拽调整大小的类，供演示页面使用。

依赖方向单向指向 `src/` 源码，测试不反向依赖其他测试文件；`StkTableTest.vue` 作为综合演示入口，通过 `registerFeature` 和 `useAreaSelection` 注册扩展功能。
