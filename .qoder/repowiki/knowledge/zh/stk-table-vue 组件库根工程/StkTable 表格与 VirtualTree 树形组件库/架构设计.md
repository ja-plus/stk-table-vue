模块由三个独立但可组合的 Vue 组件构成：
- `StkTable`（核心）：以 `StkTable.vue` 为入口，通过 `index.ts` 统一导出组件、类型与自定义单元格工厂函数；功能按职责拆分为多个 `useXxx.ts` 组合式 Hook（如 `useVirtualScroll`、`useSorter`、`useTree`、`useAreaSelection`、`useColResize`、`useFixedCol` 等），每个 Hook 封装一项能力并注入到主组件中。
- `registerFeature.ts` 实现按需特性注册机制：通过 `ON_DEMAND_FEATURE` 字典与 `MY_FN_NAME` 标识，允许外部调用 `registerFeature` 动态注入/替换特性（如未注册的 `useAreaSelection` 会返回空实现以避免运行时错误）。
- `custom-cells/` 目录采用统一的工厂模式：每个单元格类型（FilterCell、EditableCell、CheckboxCell、NumberCell、ChangeCell）均包含 `createXxxCell.ts` + `XxxCell.vue` + `index.ts`，对外暴露 `createXxxCell` 工厂函数供列配置使用。
- `features/` 目录存放可选特性 Hook，`const.ts` 定义特性名称常量。
- `types/index.ts` 集中定义所有公共类型（`StkTableColumn`、`SortConfig`、`AreaSelectionConfig` 等），并通过 `PrivateStkTableColumn` / `PrivateRowDT` 扩展内部私有字段。
- `VirtualTree.vue` 是独立的虚拟滚动树组件，`VirtualTreeSelect.vue` 基于 Teleport 渲染下拉面板并复用 VirtualTree，二者均为 Options API 风格单文件组件。
- 依赖方向：StkTable → use* Hooks → utils/types；VirtualTreeSelect → VirtualTree；custom-cells 仅被 StkTable 消费。
