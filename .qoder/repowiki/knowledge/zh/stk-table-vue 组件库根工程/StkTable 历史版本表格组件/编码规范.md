- 组件通过 props 声明配置项并使用 `{ type, default }` 形式定义默认值，事件通过 `emits` 数组显式声明。
- 表格列配置统一使用 `dataIndex` 作为唯一键，支持 `customCell` 和 `customHeaderCell` 插槽自定义单元格渲染。
- 虚拟滚动通过计算属性 `virtual_on`、`virtual_dataSourcePart` 控制可见行切片，滚动事件监听后调用 `updateVirtualScrollY/X` 更新 startIndex 和 offset。
- 排序逻辑抽离为纯函数 `tableSort` 和 `insertToOrderedArray`，支持 number/string 类型及自定义 sorter 函数。
- 固定列在高性能浏览器中使用 CSS `position: sticky`，低版本浏览器（Chrome < 56）回退到 `relative` 定位加手动 left/top 计算。
- 组件内部状态使用响应式对象包裹（如 `currentItem: { value: null }`）以便跨组件共享引用。
