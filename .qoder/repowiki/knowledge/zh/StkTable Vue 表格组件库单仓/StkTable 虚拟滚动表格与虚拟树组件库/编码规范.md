- 自定义单元格统一采用工厂函数模式：每个单元格类型提供 `createXxxCell.ts` 导出工厂函数，并在 `index.ts` 中重新导出对应类型定义。
- 可选特性通过 `registerFeature` 注册到 `ON_DEMAND_FEATURE` 字典，特性函数需暴露 `MY_FN_NAME` 标识键以便框架识别。
- 公共类型集中在 `types/index.ts`，并通过 `Private*` 前缀区分对外接口与内部私有字段（如 `PrivateStkTableColumn`、`PrivateRowDT`）。
- 常量（默认值、颜色、浏览器兼容判断等）统一放在 `const.ts` 中管理，避免散落在业务逻辑中。
- 每个 use* Hook 封装单一职责（虚拟滚动、排序、固定列、区域选区等），通过组合式 API 注入到 StkTable 主组件。
