该目录为构建输出产物，由源码编译打包生成三个 JS 文件与一个 CSS 文件：
- `stk-table-vue.js`：主入口，聚合导出 StkTable 及各类 custom-cell 工厂函数（createFilterCell、createEditableCell、createCheckboxCell、createNumberCell、createChangeCell），并通过动态 import 按需加载 Dropdown 弹窗。
- `StkTable-BK4VNsvG.js`：核心表格逻辑与工具函数（排序、二分查找、格式化等），被主入口与其他模块依赖。
- `Dropdown-wEI6qpCx.js`：筛选下拉弹窗的独立 chunk，通过 `getDropdownIns()` 懒加载挂载到 body，避免首屏冗余。
- `style.css`：组件样式。
依赖方向单向：主入口 → StkTable + 各 cell 工厂 → 按需加载 Dropdown；无循环依赖。
