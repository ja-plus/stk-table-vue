该模块是独立的文档演示工程，以根目录 `StkTable.vue` 作为 VitePress 环境下的统一入口：通过 `registerFeature([useAreaSelection])` 注册区域选择插件，将 `$attrs` 和所有 slot 透传给底层 `../src/StkTable` 组件，并通过 `defineExpose` 暴露高亮、排序、滚动等实例方法供示例调用。

- 目录按功能维度分层组织：`basic/` 展示表格基础能力（对齐、边框、复选框、固定列、合并单元格、树形、排序、主题等），每个子目录一个独立 `.vue` 示例；`advanced/` 聚焦高级特性（虚拟滚动、自定义单元格、行拖拽、列宽调整、高亮、区域选择等），部分子目录采用 `index.vue + types.ts` 的结构化组织；`demos/` 为综合场景（海量数据、矩阵表、面板树、实时合并、虚拟列表等），通常包含 `columns.ts`、`mockData.ts`、`types.ts` 等辅助文件。
- `components/` 提供跨示例复用的通用 UI 控件（CheckItem、RadioGroup、RangeInput）；`hooks/useI18n/` 封装多语言支持，依赖 VitePress 的 `useData()` 获取当前语言，并按 `zh.ts`、`en.ts`、`ja.ts`、`ko.ts` 分文件维护语言包。
- 依赖方向单向指向 `../src/StkTable`，演示代码不反向依赖业务逻辑，仅消费其 API 与类型定义。
- `tsconfig.json` 配置了 `@/*` → `../src/*` 的路径别名，使示例可直接引用源码中的类型与工具函数。
