该目录为只读构建产物，由源码编译生成三个 JS 文件与一个 CSS 文件，依赖方向单向无环：
- `stk-table-vue.js`：主入口，聚合导出 StkTable_default 及 createFilterCell/createEditableCell/createCheckboxCell/createNumberCell/createChangeCell 等工厂函数，并通过动态 import('./Dropdown-iW-rY3I6.js') 懒加载 Dropdown 弹窗。
- `StkTable-Deyo4iqb.js`：核心表格逻辑与工具函数（排序、二分查找、格式化、区域选择 useAreaSelection 等），被主入口与其他模块依赖。
- `Dropdown-iW-rY3I6.js`：筛选下拉弹窗独立 chunk，通过 getDropdownIns() 单例缓存挂载到 body，避免首屏冗余。
- `style.css`：组件样式。
每个 JS 文件顶部保留统一 JSDoc 元信息块（name/version/description/author/homepage/license），通过 `//#region` 注释标注源码路径以便调试映射。
