- 多语言文档采用镜像目录结构：`main/`、`demos/` 下的每个 Markdown 文件在 `en/`、`ja/`、`ko/` 下保持同名同路径一一对应。
- 示例页面统一使用 `<demo vue="..." github="...">` 标签引用 `docs-demo` 中的 Vue SFC，并通过 `github` 属性链接到 GitHub 源码。
- 侧边栏与导航在各语言配置文件中通过 `themeConfig.sidebar` 和 `themeConfig.nav` 数组声明式定义，并按 `/main`、`/demos` 等 base 路径分组。
- 首页 `index.md` 使用 VitePress 默认的 `layout: home` front matter，通过 `hero`、`features` 字段描述站点核心卖点。
